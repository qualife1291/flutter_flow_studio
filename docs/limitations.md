# Known limitations

- Static analysis is syntax-based, not a whole-program resolved call graph. It scans non-generated Dart files under `lib/`. Same-name methods with ambiguous destinations are not linked. Dynamic dispatch, generated Retrofit/Chopper implementations and runtime-created routes may require explicit probes. HTTP-annotated API declarations can appear alongside their invocation nodes.
- Router/network recognition uses supported method names, receiver names and locally declared network types. It cannot prove every receiver's type. Arbitrary wrappers or aliases can be missed; names resembling supported clients can produce false positives. Literal Material route tables and GoRouter builders/names are resolved. Generated route wrappers, complex provider expressions, complex state predicates, and asynchronous event ordering are not exhaustively resolved.
- BLoC `on<Event>` handlers and unambiguous event dispatches are linked syntactically. State constructor emissions and notifier assignments link to matching `state is Type` conditions; literal `copyWith` field assignments link to matching enum equality predicates. Equivalence between arbitrary state predicates is not inferred.
- Sink-related `if/else`, statement `switch`, `try/catch`, and `fold/when` callbacks are sliced. Conditional expressions, switch expressions, loops, early-return dominance and exception propagation through another method are not a complete control-flow model. UI-only conditionals are omitted by starting at sinks. Health warnings are heuristics, not proof of correctness.
- Deep trace currently supports braced `if/else` branches. It does not add missing branches or instrument `switch`, `fold`, `try/catch` and expression bodies. It requires a clean Git checkout for each target file and refuses part files that cannot accept imports. It cannot restore after SIGKILL automatically; backups remain on disk. Do not edit traced files without preserving the backups.
- Confirmed coverage is probe-based, not VM Service code coverage. Web does not expose native VM Service coverage. Inferred paths never count as confirmed coverage. The UI aggregates confirmed evidence across retained sessions; event path inference stays within each session. History trimming and resets can discard evidence.
- No network adapter can intercept 100% of native HTTP stacks. Dart IO overrides do not capture Cronet, `cupertino_http`, other isolates or already-created clients. Zone-local HTTP overrides take precedence over the global capture hook; use Dio interception or explicit probes in those zones. Dio plus IO capture can duplicate events; disable one capture layer. Metadata is recorded at response-header completion, not after body download. Bodies and custom payloads are deliberately excluded by the default transport.
- Runtime routes/dialogs must match a unique graph node or explicit probe ID. Unknown events remain visible in the timeline with recovery guidance. Snackbars/toasts need explicit events. The browser cannot open a remote file using a local IDE URI unless paths match that machine's workspace.
- Node positions and dimensions are session-local UI state and reset on reload; image exports use a fresh layout of the selected graph, with long labels limited to three lines. PNG export rejects excessively large canvases; use SVG or a feature scope. Exports are editable static graphs, not a reversible representation of source code. Business/screen-only views contract hidden intermediaries for readability; the full graph and coverage evidence remain available. Low-code mode collapses recognized state bridge intermediaries; it does not summarize arbitrary business logic.
- No package release, signing credentials or store uploads are performed. Platform support still requires the build/device matrix and accessibility evidence specified by the repository's handover gate.

- Complete source contexts are captured at scan time, rather than loaded live from the IDE. Re-scan after edits. Older snapshots only contain their original snippets; Studio cannot reconstruct missing functions. Full-source snapshots can reach the 20 MiB import limit on large projects; export a smaller graph or remove source before external sharing.
