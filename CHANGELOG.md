## [0.1.0] - Unreleased

### Added

- Dart flow scanner with sink-based branch slicing, dependency inspection, business labels, health warnings, and unambiguous call/state links.
- Token-protected local HTTP/WebSocket server and CLI exports with bundled Studio assets.
- React Studio with role views, ELK layout, inspector, timeline replay, probe-based coverage, snapshot import and graph/image exports.
- Typed repository call continuations, Material/GoRouter route discovery, branch labels and sink-only pruning of UI logic.
- Runtime follow/spotlight controls, reduced-motion support and execution sequence labels; global HTTP override restoration across zones.
- Bundled third-party dependency license notices.
- Opt-in Flutter runtime observers, conditional native HTTP metadata capture, explicit probes, reconnect queue and release guard.
- Deterministic login example, unit/widget/browser tests, accessibility reports, and a multi-platform CI workflow.
